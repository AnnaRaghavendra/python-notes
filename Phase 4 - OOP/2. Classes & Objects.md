## 2.1 What is a Class?

### Definition

A Class is a blueprint or template used to create objects.

---

### Simple Meaning

```text id="c1"
Blueprint

↓

Creates Objects
```

---

### Real-World Example

Think of a house blueprint.

```text id="c2"
Blueprint

↓

House 1

House 2

House 3
```

The blueprint is the class.

The houses are objects.

---

### Python Meaning

A class describes:

```text id="c3"
Attributes

+

Methods
```

---

## 2.2 Why Classes?

Without classes:

```text id="c4"
Data

↓

Functions

↓

Repeated Again And Again
```

---

With classes:

```text id="c5"
Everything Related

↓

Grouped Together
```

---

### Benefits

```text id="c6"
Better Organization

Code Reusability

Easy Maintenance

Real-World Modeling
```

---

## 2.3 What is an Object?

### Definition

An Object is an instance of a class.

---

### Simple Meaning

```text id="c7"
Class

↓

Object
```

---

### Example

```text id="c8"
Student

↓

Ravi

Priya

Rahul
```

Student is the class.

Each student is an object.

---

## 2.4 Class vs Object

| Class             | Object             |
| ----------------- | ------------------ |
| Blueprint         | Real Instance      |
| Logical Entity    | Physical Entity    |
| Defines Structure | Stores Actual Data |
| One Class         | Many Objects       |

---

### Example

```text id="c9"
Book

↓

Python Book

Java Book

ML Book
```

---

## 2.6 Methods

### Definition

Methods are functions defined inside a class.

---

### Purpose

Methods describe what an object can do.

---

### Examples

```text id="c12"

```

---

Car:


---

## 2.7 Attributes vs Methods

| Attributes      | Methods         |
| --------------- | --------------- |
| Store Data      | Perform Actions |
| Variables       | Functions       |
| Describe Object | Define Behavior |

---

### Example

```text id="c14"

↓

Age

CGPA

↓

```

## 2.8 The `self` Keyword

### Definition

`self` refers to the current object.

---

### Simple Meaning

```text id="c15"
Current Object
```

---

### Why is `self` Needed?

Suppose two objects exist:

```text id="c16"
Student A

Student B
```

Both have:

```text id="c17"
Name

Age
```

Python uses `self` to know which object's data is being accessed.

---

### Important Rule

```text id="c18"
Every Instance Method

Receives self

As The First Parameter
```

---

### Remember

You do **not** pass `self` manually.

Python passes it automatically.

---

## 2.11 Common Mistakes

### Confusing Class and Object

Wrong:

```text id="c23"
Class

=

Object
```

---

Remember:

```text id="c24"
Class

↓

Creates

↓

Objects
```

---

### Thinking Every Variable is an Attribute

Only variables belonging to an object are attributes.

---

### Forgetting `self`

Instance methods must include:

```text id="c25"
self
```

as the first parameter.

---

### Accessing Attributes Incorrectly

Inside a class, object attributes should be accessed through:

```text id="c26"
self
```
