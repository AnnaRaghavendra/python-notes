## 2.1 What is a Class?

### Definition

A Class is a blueprint or template used to create objects.

---

### Why Classes?

Without classes:

```text
Data

↓

Functions

↓

Repeated Again And Again
```

With classes:

```text
Related Data

+

Related Methods

↓

Grouped Together
```

---

### Syntax

```python
class Student:
    pass
```

---

### Explanation

* `class` is the keyword used to create a class.
* `Student` is the class name.
* `pass` is a placeholder indicating an empty class.

---

### Real-World Example

```text
Blueprint

↓

House 1

House 2

House 3
```

Blueprint = Class

Houses = Objects

---

## 2.2 What is an Object?

### Definition

An Object is an instance of a class.

---

### Syntax

```python
student = Student()
```

---

### Explanation

* `Student()` creates a new object.
* `student` stores a reference to that object.

---

### Real-World Example

```text
Student

↓

Raghava

Rahul

Krishna
```

Class:

```text
Student
```

Objects:

```text
Raghava

Rahul

Krishna
```

---

## 2.3 Class vs Object

| Class             | Object             |
| ----------------- | ------------------ |
| Blueprint         | Instance           |
| Defines Structure | Stores Actual Data |
| One Class         | Many Objects       |

---

### Example

```text
Book

↓

Python Book

Java Book

ML Book
```

## 2.4 Attributes

### Definition

Attributes are variables that belong to an object.

---

### Syntax

```python
class Student:
    def __init__(self):
        self.name = "Raghava"
        self.age = 20
```

---

### Explanation

Attributes store information about an object.

---

### Example Attributes

```text
Student

↓

Name

Age

CGPA
```

---

## 2.5 Methods

### Definition

Methods are functions defined inside a class.

---

### Syntax

```python
class Student:
    def study(self):
        print("Studying...")
```

---

### Explanation

Methods define what an object can do.

---

### Examples

```text
Study()

Sleep()

Display()

Graduate()
```

---

## 2.6 Attributes vs Methods

| Attributes | Methods         |
| ---------- | --------------- |
| Store Data | Perform Actions |
| Variables  | Functions       |

---

### Example

```text
Student

Attributes

↓

Name

Age

CGPA

Methods

↓

Study()

Graduate()
```

## 2.7 The `self` Keyword

### Definition

`self` refers to the current object.

---

### Why is `self` Needed?

Suppose two objects exist:

```text
Student A

Student B
```

Python must know which object's data is being accessed.

`self` provides that reference.

---

### Syntax

```python
class Student:
    def display(self):
        print(self.name)
```

---

### Important Rules

* Always the first parameter of an instance method.
* Passed automatically by Python.
* Do **not** pass it manually.

---

## 2.8 Creating Multiple Objects

### Syntax

```python
student1 = Student()
student2 = Student()
student3 = Student()
```

---

### Explanation

One class can create any number of objects.

Each object has its own data.

## 2.10 Common Mistakes

### Confusing Class and Object

Wrong:

```text
Class = Object
```

Correct:

```text
Class

↓

Creates

↓

Objects
```

---

### Forgetting `self`

Every instance method requires:

```text
self
```

---

### Accessing Attributes Incorrectly

Inside a class, use:

```python
self.attribute_name
```

---

### Using Attributes Before Initialization

Initialize attributes before using them.
