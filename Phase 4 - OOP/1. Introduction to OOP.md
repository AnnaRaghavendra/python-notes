## 1.1 What is OOP?

### Definition

Object-Oriented Programming (OOP) is a programming paradigm that organizes programs using **objects**, which contain both **data (attributes)** and **behavior (methods)**.

---

### Simple Meaning

```text
Everything Is Represented As Objects
```

---

### Examples of Objects

```text
Car

Student

Bank Account

Book

Mobile Phone

Employee
```

Each object has:

```text
Data

+

Behavior
```

---

## 1.2 Why OOP?

Before OOP, most programs were written using procedural programming.

As software became larger:

```text
More Code

↓

More Complexity

↓

Difficult To Maintain
```

OOP was introduced to make programs:

```text
Organized

Reusable

Maintainable

Scalable
```

---

## 1.3 Procedural Programming vs OOP

### Procedural Programming

Focuses on:

```text
Functions

↓

Steps

↓

Procedures
```

---

### Object-Oriented Programming

Focuses on:

```text
Objects

↓

Data

+

Behavior
```

---

### Comparison

| Procedural Programming          | Object-Oriented Programming    |
| ------------------------------- | ------------------------------ |
| Function-Oriented               | Object-Oriented                |
| Data and Functions are Separate | Data and Methods Stay Together |
| Less Reusable                   | Highly Reusable                |
| Harder to Maintain              | Easier to Maintain             |
| Suitable for Small Programs     | Suitable for Large Projects    |

## 1.10 Common Mistakes

### Thinking OOP Means Only Classes

Wrong.

OOP is a complete programming paradigm.

---

### Memorizing Definitions

Understanding concepts is more important than memorizing terminology.

---

### Using OOP Everywhere

Not every program needs OOP.

Simple scripts may be easier to write procedurally.

---

### Ignoring Design

Good OOP focuses on designing relationships between objects, not just writing classes.
